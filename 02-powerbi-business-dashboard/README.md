# Power BI Superstore Sales & Profit Analysis

## Project Overview
This project uses the Sample Superstore dataset to analyze retail sales, profitability, order volume, and sales performance against an illustrative target using Microsoft Power BI.

## Objectives
- Analyze sales and profit across product categories and regions.
- Track monthly sales trends.
- Identify sub-categories with negative profitability.
- Compare actual sales with an assumed sales target.
- Present business insights through an interactive dashboard.

## Key Performance Indicators
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Target Achievement

## Key Insights
- Technology recorded the highest sales among the product categories.
- The West region recorded the highest profit.
- Tables, Bookcases, and Supplies showed negative profit in the analysis.
- Sales target achievement is measured against an illustrative target of $2.5 million.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data visualization and business analysis

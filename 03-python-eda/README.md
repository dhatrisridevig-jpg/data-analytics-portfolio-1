# Superstore Sales & Profitability Analysis — Python EDA

##  Project Overview

This project explores the Sample Superstore dataset using Python to analyze sales performance and profitability across product categories, sub-categories, and regions.

The objective is to transform raw sales data into meaningful visualizations and develop an understanding of business performance through Exploratory Data Analysis (EDA).

##  Project Objectives

- Analyze sales performance across product categories.
- Identify profit patterns across product sub-categories.
- Compare profitability across different regions.
- Compare regional sales and profit performance.
- Understand category-wise contribution to total sales.
- Present business data through clear and informative visualizations.

##  Tools & Technologies

- **Python** — Data analysis and visualization
- **Pandas** — Data loading, grouping, and aggregation
- **Matplotlib** — Data visualization
- **Jupyter Notebook** — Code execution and analysis

##  Dataset

**Dataset:** Sample Superstore

The dataset contains sales transaction information, including product categories, sub-categories, regions, sales, and profit.

The Excel dataset was loaded into Python using Pandas for analysis.

##  Analysis Performed

The project includes the following visualizations:

1. **Sales by Category** — Compares total sales across product categories.
2. **Profit by Sub-Category** — Examines profitability across product sub-categories.
3. **Profit by Region** — Compares profit generated by different regions.
4. **Sales vs. Profit by Region** — Evaluates regional sales performance alongside profit.
5. **Sales Contribution by Category (Pie Chart)** — Shows each category's percentage contribution to total sales.

##  Key Business Questions

- Which product categories contribute to total sales?
- How does profitability vary across sub-categories?
- Which regions generate higher profits?
- Do higher regional sales correspond to higher profits?
- How is total sales revenue distributed across categories?

##  Business Value

The analysis demonstrates how exploratory data analysis can help businesses understand sales distribution, evaluate regional performance, identify profitability differences, and support data-driven decision-making.

Comparing sales with profit is particularly important because higher revenue does not necessarily mean higher profitability.
